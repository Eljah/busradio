    Реклама рядом с маршрутом

    Как выбирается ролик

    1

    Свежий GPS, приемлемая точность и совпадение с направлением маршрута.

    2

    Объект в радиусе, не позади автобуса, кампания активна, лимиты не исчерпаны.

    3

    Ближайший подходящий объект. В оставшееся окно помещается ролик целиком.

    Остановочная цепочка — приближение, а не точная линия дороги. Для петель и развязок загрузите проверенную полилинию.
