# Проверка сборки 0.1.0

Дата подготовки: 2 октября 2026. Среда: Linux x86_64, OpenJDK 21.0.11. Это хостовая программная проверка, а не Raspberry Pi / RF-стенд.

Выполнено:
- `javac --release 21` для busradio-core, server, edge, tests.
- 38 проверок `SelfTest`: **38 успешно, 0 ошибок**.
- Настоящий JDK HttpServer на локальном ephemeral-порту и настоящий JDK HttpClient, не подмена ответов.
- Настоящий FFmpeg преобразовал синтетический WAV в канонический PCM; хеш и длина совпали.
- Реальная дисковая докачка, подписи Ed25519, атомарная активация, повреждение нового файла, последующее восстановление, запрет отката и ремонт кеша.
- Офлайн-плеер создал WAV ровно из 4 секунд песни и 8 секунд окна. Проверены полные ролики, заполнение остатка и отсутствие георекламы без GPS.
- Реальные HTTP аутентификация, CSRF, Origin, привязка токена к борту, Range, отказ в доступе к неопубликованному хешу.
- Повторная доставка событий, перезапуск журнала и восстановление после незавершённой последней записи.
- Дочерний Java-процесс PcmProbe получил один WAV-заголовок и два PCM-блока. Это проверяет pipe-интеграцию, **не FM**.
- `node --check` проверил синтаксис app.js.

Не выполнено:
- `mvn verify`: Maven отсутствовал, установка/получение внешних зависимостей были недоступны. Версии плагинов и Pi4J закреплены в POM, но полный Maven-reactor не запускался.
- Модуль Pi4J не компилировался с реальными jar-зависимостями здесь; псевдоклассы вместо Pi4J не создавались.
- Настоящие GPIO, зажигание, GPSD с физическим GNSS и нативный fm_transmitter на ARM.
- Браузерный E2E: Chromium доступен, но навигация к локальному HTTP-серверу заблокирована политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`). Политика не отключалась. Рабочий скриншот UI не заявляется.
- Пробный рейс, измерение RF-спектра, долговременный/нагрузочный/аварийный тест оборудования и OS NetworkManager/firewall.

## Повторение

```bash
mvn --batch-mode --no-transfer-progress verify
# Либо без внешних Java-зависимостей и без Pi4J:
bash scripts/build-local.sh
```

SelfTest не требует JUnit: выполняется Maven exec plugin на фазе verify. XML-отчёт совместим с форматом JUnit. Можно задать каталог `-Dbusradio.reports=/path/to/reports` и путь к FFmpeg `-Dbusradio.test.ffmpeg=/path/to/ffmpeg`.

Исходный успешный отчёт приложен как `docs/verification-2026-10-02.txt`; свежий после локального прогона находится в `busradio-tests/target/test-results/`. Тесты используют синтетические строки координат и звуковые тоны, без записей пассажиров/водителей, настоящих рекламодателей и коммерческой музыки.
