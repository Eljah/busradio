# Одноплатный компьютер, Pi4J и экспериментальный FM

## Разделение функций

Java 21 управляет загрузкой, расписанием, GPS и PCM. Pi4J 3.0.4 / GpioD читает BCM17 (разрешение воспроизведения от подготовленного входа зажигания) и управляет индикатором BCM27. Эти пины настраиваются; GPIO4 и GPIO21 зарезервированы от случайного использования Pi4J, поскольку нативный FM-backend может использовать один из них.

FM не генерируется вызовами DigitalOutput.high()/low(). Нативный `markondej/fm_transmitter` использует аппаратное тактирование GPIO. Java держит один процесс и передаёт ему один WAV-заголовок и непрерывный поток PCM16 mono 22050 Гц. Песни и реклама переключаются внутри потока. Процесс не скачивается сервером и не запускается из содержимого рекламной кампании.

Подтверждённые внешние сведения:
- Pi4J V3 требует Java 21; 3.0.4 опубликован 21.05.2026: https://www.pi4j.com/about/release-notes/
- GpioD provider и настройки: https://www.pi4j.com/documentation/providers/gpiod/
- Нативный генератор, его зависимости, формат stdin и оговорки по Pi4: https://github.com/markondej/fm_transmitter

Upstream указывает платы до Raspberry Pi 4 включительно и отсутствие поддержки Pi 5 из-за RP1. Даже для Pi4 описаны ограничения частот/тактового режима. Совместимость Pi4J с Pi5 не переносит на Pi5 этот FM-метод. `busradio` дополнительно допускает в RF-режиме только строки модели Pi3, Pi4, Zero2: это консервативный gate, не результат аппаратного теста.

## Подготовка обычного бортового режима

Установите Java 21; полная Maven-сборка содержит Pi4J, но для GpioD нужны подходящие библиотеки/доступ к gpiochip согласно документации Pi4J и вашей ОС. Системный пользователь должен иметь необходимые права на GPIO/audio, не на всё устройство. Проверьте совместимость 32/64-bit native библиотек с вашей архитектурой: она здесь не испытывалась.

GNSS: используйте приёмник и GPSD на `127.0.0.1:2947`. Приёмник должен выдавать время, позицию, курс при движении и оценку погрешности. Отсутствие точности не считается идеальным GPS. В помещении, при потере фикса или чрезмерной погрешности прозвучит FILLER, а не случайная геореклама.

Настройте доверенные Wi-Fi-профили в NetworkManager. В edge.properties перечислите разрешённые SSID через `|`, интерфейс wlan0 и ночное окно. SSID сам по себе не удостоверяет сеть — HTTPS и заранее установленный ключ обязательны. Политика проверяет состояние перед запросами и во время передачи, но не даёт строгой гарантии при мгновенной смене маршрута ОС. Для запрета мобильного трафика используйте per-UID firewall, см. deploy/edge-egress.nft.example; пример не применяется автоматически.

Сохраните конфигурацию `/etc/busradio/edge.properties` с режимом 0600. Начните с `hardware.enabled=false`, `audio.mode=wav` или `null`, `rf.enabled=false`. Сначала проверьте синхронизацию и GPS, затем GPIO, затем звук через обычный локальный аудиовыход.

## Автомобильная электрика

**GPIO не допускает прямого подключения к линии 12/24 В, контактам зажигания и автомобильной нагрузке.** Нужен спроектированный вход с гальванической развязкой/защитой и выходом допустимого для SBC уровня, устойчивый к выбросам и переполюсовке. Питание SBC — от автомобильного DC/DC с защитой, предохранителем и корректным отключением/резервом энергии для файловой системы. Резистор для LED и схема согласования выбираются по реальным компонентам. Комплект сертифицированной электрической схемы и расчёт перенапряжений в эту программную версию не входят.

Pi4J-вход блокирует воспроизведение при выключенном зажигании. Программный interlock не заменяет физический выключатель/обесточивание передающей части. Штатное пассажирское оповещение и связь водителя должны иметь независимый приоритет; такой интерфейс в v0.1 не реализован.

## FM-режим: только после стендовой проверки

Нативный исходный проект не включён в репозиторий busradio: его нужно независимо получить, проверить и собрать по документации upstream на выбранной Pi. Java вызывает установленный абсолютный путь в форме `fm_transmitter -f <frequencyMHz> -`; применяется WAV stdin, без оболочки. Upstream обычно требует привилегированный доступ к физической памяти. **Не выдавайте root всей Java-службе только ради этого.** Изоляция привилегированного native-helper и его аппаратные права требуют отдельного развёртывания; в стандартном systemd unit намеренно включён `NoNewPrivileges=true`, и доступа к `/dev/mem` он не выдаёт. Прямой FM запуск от этого unit «из коробки» не обещается.

Локальная конфигурация содержит gates:

```properties
audio.mode=fm
audio.realtime=true
rf.enabled=true
rf.authorization=REFERENCE_TO_YOUR_ACTUAL_APPROVAL_OR_CONTROLLED_BENCH_PROCEDURE
rf.frequencyMHz=
rf.executable=/usr/local/bin/fm_transmitter
```

Частота намеренно оставлена пустой: выберите её только в рамках действующего разрешения/условий измерительного стенда. Строка authorization — запись основания, не юридическое разрешение и не измерение помех. Synthetic GPS запрещён совместно с FM. Режимы WAV/null ничего не излучают.

Не начинайте с антенной в автобусе. Сначала нужен контролируемый измерительный стенд с экранированием/согласованной нагрузкой, анализатор спектра и подходящая фильтрация гармоник. Установленные сигнальные уровни, паразитные излучения, взаимодействие с GNSS/радиосвязью, соответствие нормам и разрешённость коммерческого распространения аудио должны быть проверены компетентным специалистом. Длина провода не ограничивает спектр или дальность предсказуемым способом.

Программный watchdog завершает зависший дочерний процесс; при штатном завершении посылается TERM, затем при необходимости принудительное завершение. Однако **остановка процесса не является измеренным подтверждением остановки аппаратного тактового выхода**, особенно после аварии/kill. Аппаратное выключение RF и проверка спектра необходимы отдельно. Непрерывный процесс ограничен 12 часами; после лимита агент завершится и может быть перезапущен systemd. Это также предотвращает переполнение 32-битного WAV-заголовка.

В этой работе на физической Raspberry Pi FM не запускался; RF-помехи, покрытие салона и работоспособность на выбранной ОС не измерялись. Это намеренно обозначенная непроверенная аппаратная часть, а не «симуляция, выданная за эфир».
