## routes.json

`nbusstop[id] = [название, долгота, широта, ...]`.
`bus[internalRouteId]`: индекс 1 — отображаемый номер маршрута; индекс 5 в исходном проекте — вид транспорта.
`route[rowId] = [internalRouteId, stopId, direction, stopOrder, ...]`.

Импорт группирует по внутреннему ID и направлению, сортирует по stopOrder, создаёт ID `internalRouteId:direction`. Дубликат порядкового номера — ошибка; отсутствующие ссылки дают предупреждение; разрыв порядка не соединяется фиктивным сегментом. Вид транспорта в выборке busradio отдельно не классифицируется: администратор должен выбрать именно нужные автобусные маршруты.

Полученная линия — `STOP_CHORDS`. Она не содержит повороты между остановками. В редакторе можно заменить точки на проверенную полилинию `SHAPE`, сохранив ID. Автоматического скачивания карт и восстановления дорожных shapes в v0.1 нет. Overlay `navi-route-map.json` автоматически не импортируется; дополнительные направления нужно загрузить нормализованными Route JSON.

## Движение

Нормализованная строка JSONL: `source`, `plate` / `naviUnitId`, `latitude`, `longitude`, `speed`, `course`, `timestamp`, `sourceTimestamp`.

В `BusNaviRealtimeClient` speed взят из u_speed в км/ч: адаптер переводит в м/с. timestamp — время получения записи; sourceTimestamp — время измерения. Для `source=navi` отсутствие sourceTimestamp отклоняется. Старые координаты никогда не становятся свежими из-за повторного чтения файла. Для старого не-Navi формата допускается timestamp, что требует правильной интерпретации времени источником.

```properties
gps.mode=buscrawl
gps.buscrawlFile=/var/lib/buscrawl/vehicle.jsonl
gps.vehicle=EXACT_PLATE_OR_NAVI_UNIT_ID
```

Клиент читает хвост до 64 КиБ, ищет последнюю подходящую завершённую/валидную строку для заданной машины. Архивный файл не обеспечивает навигацию: через 15 секунд геореклама перестанет выбираться. Для полностью автономного рейса предпочтителен собственный GNSS-приёмник через GPSD. Buscrawl здесь служит источником топологии и формата, а не выдуманным общедоступным REST API.

`fixtures/` содержит только синтетические примеры. Файл движения намеренно имеет фиксированное время и не должен использоваться как свежий GPS.
